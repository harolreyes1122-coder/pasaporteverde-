PASAPORTE VERDE CAFÉ — ANDROID CON LOGO

Este proyecto conserva la interfaz y funciones de Pasaporte Verde Café.
El logo está configurado oficialmente como icono del launcher de Android.

Incluye:
- Nombre de app: Pasaporte Verde Café
- Icono normal y redondo
- Icono adaptativo para Android 8+
- Tamaños mdpi, hdpi, xhdpi, xxhdpi y xxxhdpi
- Cámara habilitada en AndroidManifest.xml
- App web incluida offline en app/src/main/assets/index.html
- QR, trazabilidad, lotes, ambiente, aguas mieles, mujeres, calidad,
  variedad y mercado conservados.

PARA GENERAR APK EN ANDROID STUDIO:
1. Abrir esta carpeta como proyecto.
2. Esperar la sincronización de Gradle.
3. Build > Build APK(s).
4. El APK estará en app/build/outputs/apk/debug/app-debug.apk

El APK instalado mostrará el logo de Pasaporte Verde Café en el menú del teléfono.
